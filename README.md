# Edvexa Data Quality ETL Monitor

A beginner-friendly Python project for learning CodeZero.

The project will validate customer CSV files, detect duplicate customer IDs, normalize data, and export clean records and validation errors.

## Planned Features

- CSV data validation
- Email validation and normalization
- Duplicate customer ID detection
- Clean CSV export
- Validation error report
- Automated tests with pytest
